# Madrid Bunny

A lightweight web video player page that loads stream metadata from `data.json` and displays each stream through an embedded player.

## Features

- Simple browser-based video listing
- Stream details loaded from JSON
- Embedded external video players
- Minimal HTML, CSS, and JavaScript structure

## Project Structure

- `index.html` — Main player page
- `player.js` — Loads stream data and builds the video cards
- `data.json` — Stream titles, descriptions, and player URLs
- `style.css` — Page styling
- `vercel.json` — Deployment configuration

## Usage

Open `index.html` through a compatible web server or deploy the project to a static hosting service.

To add or change a stream, update the entries in `data.json`.

## Note

Use only stream sources and embedded content that you are authorized to access and distribute.
